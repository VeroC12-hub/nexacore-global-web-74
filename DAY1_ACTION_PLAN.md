### 🔍 TASK 2: Google Search Console (30 min)

**What you're doing:** Telling Google about your website

**Why it matters:** Google will crawl and index all your pages so people can find you in search!

**Steps:**
1. Open browser → https://search.google.com/search-console
2. Click "Start now"
3. Sign in (same Gmail as Google Business)
4. Click "+ Add property"
5. Select "URL prefix"
6. Enter: **https://nexacore-innovations.com**
7. Click "Continue"

**NOW - Verification:**
```
Google will show you a verification code that looks like:
<meta name="google-site-verification" content="abc123XYZ......" />

COPY the code between the quotes: abc123XYZ......
```

**Add code to your website:**
```
1. Open file: C:\Users\Vero C\nexacore-global-web-74\index.html
2. Find line 16 (search for "google-site-verification")
3. It currently says:
   <!-- <meta name="google-site-verification" content="YOUR_VERIFICATION_CODE" /> -->

4. Remove the <!-- and --> to uncomment it
5. Replace YOUR_VERIFICATION_CODE with your actual code
6. Save the file

Example of final line:
<meta name="google-site-verification" content="abc123XYZ" />
```

**Deploy to Vercel:**
```
Option A (If connected to GitHub):
1. git add .
2. git commit -m "Add Google Search Console verification"
3. git push
4. Vercel will auto-deploy

Option B (Manual):
1. Open https://vercel.com
2. Go to your project
3. Click "Deployments"
4. Click "Deploy" → Upload the updated files
```

**Verify in Google Search Console:**
```
1. Go back to Google Search Console
2. Click "Verify"
3. Wait 30 seconds
4. Should say "Ownership verified" ✅
```
