## 🆘 NEED HELP?

**Common Issues:**

**Can't create Twitter account?**
→ Use different email (create nexacore.social@gmail.com)
→ Verify your phone number

**Instagram asking for phone verification?**
→ Normal security measure - use your phone number
→ Verification code arrives via SMS

**Facebook page creation blocked?**
→ Your personal account needs to be at least 14 days old
→ Must have verified email on personal account

**Directory submission rejected?**

→ Make sure website is live and professional
→ Add more details to company profile

→ Use Canva.com to resize
