# NexaCore Innovations Website

A modern, responsive website for **NexaCore Innovations**, a multidisciplinary engineering, technology, and digital services company serving clients globally.

## 🌟 Features

* **AI-Powered Assistant**: Built-in virtual assistant to support visitors in real-time
* **Global SEO Optimized**: Search engine visibility for international reach
* **Multi-Device Support**: Fully responsive on desktop, tablet, and mobile
* **Service-Centric Layout**: Highlights core business services clearly
* **Modern UI/UX**: Elegant, professional, and intuitive design

## 📋 Prerequisites

* Node.js >= 14.x
* npm or yarn
* Git

## 🏃‍♂️ Quick Start

```bash
git clone https://github.com/nexacore/global-web.git
cd global-web
npm install
```

### Run Locally

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000)
