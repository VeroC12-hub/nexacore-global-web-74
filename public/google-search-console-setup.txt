# Google Search Console Setup for NexaCore Innovations

## Step 1: Add Your Website
1. Go to: https://search.google.com/search-console/
2. Click "Add Property"
3. Select "URL prefix"
4. Enter: https://www.nexacore-innovations.com
5. Click "Continue"

## Step 2: Verify Ownership
Choose one of these verification methods:

### Method 1: HTML Meta Tag (Recommended)
1. Google will provide a meta tag like this:
   <meta name="google-site-verification" content="YOUR_CODE_HERE" />
2. Add this to your index.html file in the <head> section
3. The meta tag is already added to your HTML template

### Method 2: HTML File Upload
1. Download the verification file Google provides
2. Upload it to your website's public folder
3. Verify the file is accessible at: https://www.nexacore-innovations.com/google[VERIFICATION_CODE].html

## Step 3: Submit Your Sitemap
After verification is complete:
1. In Search Console, go to "Sitemaps" in the left menu
2. Add your sitemap URL: https://www.nexacore-innovations.com/sitemap.xml
3. Click "Submit"

## Step 4: Monitor Your Results
Key areas to monitor:
- Performance: Track clicks, impressions, CTR, and average position
- Coverage: Ensure all important pages are indexed
- Core Web Vitals: Monitor page experience signals
- Manual Actions: Check for any penalties
